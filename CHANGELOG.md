# Changelog

## 1.0.0 — 2026-04-16

- Initial Cloudron package: DeerFlow **v2.0-m1** upstream pin, gateway mode (nginx + Next.js + FastAPI), `localstorage` + `postgresql` + `docker` addons, Better Auth secret on `/app/data`, optional Postgres checkpointer merge at boot, `cloudron-postgresql` skill, tooling (pandoc, poppler, qpdf, ffmpeg, ImageMagick, zip/unzip, `postgresql-client`, Docker CLI).
- Default `config.yaml` seeds an **Ollama** model; Docker image installs **`deerflow-harness[ollama]`** (same as upstream’s optional extra) so operators do not run extra `uv pip` steps.
- **`runtimeDirs`**: `/app/code/backend/.langgraph_api` is writable per [Cloudron manifest](https://docs.cloudron.io/packaging/manifest/#runtimedirs); removed symlink into read-only `/app/code` (fixes startup `ln: Read-only file system`).
- **Startup**: `chown` nginx temp dirs under `/run/nginx` so nginx (non-root) does not hit `Permission denied` on `client_temp`; gateway uses `.venv/bin/python -m uvicorn` instead of `uv run` (fixes `Failed to spawn: uvicorn`); frontend uses `cloudron/run-frontend.sh` for Better Auth base URL from `CLOUDRON_APP_ORIGIN`.
- **Backend venv path**: build `uv sync` under `/app/code/backend` (not `/build/backend`) so editable `deerflow-harness` paths match the runtime tree (fixes `ModuleNotFoundError: No module named 'deerflow'`). Nginx logs to `/run/nginx/*.log` instead of `/dev/stdout` (fixes `open() "/dev/stdout" failed (13: Permission denied)` for the non-root worker).
- **Gateway workers**: pass `GATEWAY_WORKERS` into supervisord’s gateway `environment=` (the previous closed `environment=` list dropped it, so uvicorn always used `--workers 2`). With the **postgresql** addon, force **`GATEWAY_WORKERS=1`** so LangGraph Postgres checkpointer migrations do not run in parallel (`UniqueViolation` on `checkpoints` / `checkpoint_migrations`).
- **Better Auth base URL**: the frontend `environment=` list drops Cloudron vars; **`write_frontend_better_auth_env.py`** (run from **`start.sh`** before **`exec supervisord`**) reads **`os.environ`**, derives **`https://$CLOUDRON_APP_DOMAIN`** when **`CLOUDRON_APP_ORIGIN`** is absent, and writes **`/run/supervisor/frontend_cloudron.env`** as shell-safe **`export …`** lines for **`run-frontend.sh`** to **`source`** (so **`cloudron env` `BETTER_AUTH_BASE_URL`** is honored). Next production builds can still inline **`process.env.BETTER_AUTH_BASE_URL`** as empty at build time, so the script also writes **`/run/supervisor/frontend_cloudron_next.json`** and the frontend build uses **`cloudron/patches/better-auth-config.ts`** (overwrites **`src/server/better-auth/config.ts`**) to pass **`baseURL: resolveBaseURL()`** that reads that JSON first.
